CAUSES POSSIBLES:
-----------------

1. FIREWALL / RÉSEAU:
   - Les ports SMTP (587, 465) sont peut-être bloqués par votre firewall
   - Votre FAI (Fournisseur d'Accès Internet) peut bloquer les ports SMTP sortants
   - Votre routeur peut avoir des restrictions

2. GMAIL BLOQUE LA CONNEXION:
   - Gmail peut bloquer les connexions depuis votre IP pour des raisons de sécurité
   - Le mot de passe d'application peut être incorrect ou expiré
   - L'authentification à deux facteurs n'est peut-être pas activée

3. MOT DE PASSE D'APPLICATION:
   - Le mot de passe fourni (gxvwifedvgemdrge) peut ne pas être un mot de passe 
     d'application valide
   - Il doit être généré depuis: https://myaccount.google.com/apppasswords
   - Il doit être de 16 caractères (sans espaces)

SOLUTIONS RECOMMANDÉES:
-----------------------

1. VÉRIFIER LE MOT DE PASSE D'APPLICATION:
   a) Allez sur: https://myaccount.google.com/security
   b) Assurez-vous que l'authentification à deux facteurs est activée
   c) Allez sur: https://myaccount.google.com/apppasswords
   d) Créez un nouveau mot de passe d'application:

      - Sélectionnez "Autre (nom personnalisé)"

   e) Utilisez ce nouveau mot de passe dans la configuration

2. VÉRIFIER LE FIREWALL:
